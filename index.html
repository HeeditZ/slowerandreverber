    Overview

    Slower & Reverber is a browser-based audio manipulation tool built for slowed/reverb edits, pitch correction, and creative sound design. Everything runs locally on you're browser!

    Load single or multiple files, build a playlist, apply effects per-track or globally, then export. Built entirely with the Web Audio API.

    Features
    • Multi-file playlist
    • Per-track or global settings
    • Shuffle and repeat modes
    • Live waveform display
    • Speed (0.25x to 2x)
    • Pitch shift (±12 semitones)
    • Bass boost EQ
    • Studio reverb
    • Echo with feedback
    • WAV and MP3 export
    • Batch ZIP export
    • Video frame extractor
